# Kumari Akanksha — Portfolio

Personal academic portfolio built with Next.js, TypeScript and Tailwind CSS.

Live site: https://akanksha2160.github.io/portfolio/

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to ./out
```

Content lives in `lib/data.ts`. Pushes to `main` are deployed to GitHub Pages by `.github/workflows/deploy.yml`.
